# Test specification — TS-GA4-002

Executable cases, not evidence. AC text: work-item.json. Reuse Jest + `@testing-library/react-native` (mobile), existing Jest for web catalog, Maestro `qa/mobile` for native regression. Tests use the recording provider; no real Firebase call in automated tests. Never send to production to prove realism.
