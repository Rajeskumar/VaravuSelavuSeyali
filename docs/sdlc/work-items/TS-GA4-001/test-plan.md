## Evidence and sequencing

Demonstrate meaningful failing-first tests for environment isolation, revoked consent and unsafe URL behavior before fixes. Expected audit gaps do not count as passing implementation evidence. Reuse Jest/RTL and Playwright; no added analytics library. Outbound tests must inspect serialized payloads, not only mocked gtag calls. A real-tag local run aborts collectors; DebugView uses only the separate test property. Never send to production to prove a test is realistic.

Required IDs: `checks`, `schema-unit`, `navigation`, `consent-identity`, `business-events`, `outbound-payloads`, `ga4-admin-runtime`, `reporting`, `code-review`, `security-review`, `ui-review`, `product-review`, `acceptance`. Record full current source snapshots for high risk, exact command/environment/result and AC coverage. Native device evidence not applicable because native analytics/code is excluded; future native work needs its own lifecycle tests. Current Phase 1 requires documentation/schema/link checks only, with optional existing focused tests for baseline evidence.
