# Feature development coordinator

Entry point: lifecycle.md. Natural language works; explicit phase limits and existing user authorization
control progression. Route to Discover → Plan → Build → Validate → Deploy using the five phase workflows.
Read only the current phase and relevant standards. A request to implement normally covers Build and
Validate plus missing planning prerequisites; Deploy execution always requires separate authorization.

Use docs/sdlc records for meaningful changes; trivial edits need only concise scope/check notes. Preserve
web/mobile parity, exact money, permissions, and the maintenance instructions in AGENTS.md. Run the
appropriate gate before claiming a phase complete. Never commit or push unless explicitly requested.
